# Support and governance expectations

weppcloud-wbt is an open-source fork maintained as an operational dependency for WEPPcloud workflows.

## Support model

- This project is maintained by a single maintainer and is provided on a best-effort basis.
- Bug reports are prioritized over feature requests.
- Urgent infrastructure issues that impact reproducible modeling workflows are addressed first.

## Communication channels

- Use the GitHub issue tracker for reproducible bugs and questions.
- For sensitive issues (security, data integrity, private deployment details), contact the maintainer directly.

## Governance expectations

- The maintainer is the final decision maker on scope and release timing.
- Proposals should be practical, scoped, and compatible with WEPPcloud operational requirements.
- Contributions that do not include clear validation or regressions may be deferred.

## Long-term availability

The maintainer publishes updates when substantive changes land and tracks behavior changes in the changelog.
